# 📄 PDF-Flow

> A powerful, free, and privacy-first PDF editor designed for students and professionals.

## 🚀 Why PDF-Flow?

Students often face the hassle of converting PDFs to Word just to make a small change, only to convert them back – often losing formatting in the process. **PDF-Flow** eliminates this extra work. Edit your PDFs directly in the browser, 100% client-side.

### ✨ Key Features

- **⚡ Instant Editing**: Click and type to modify text. No complex conversions required.
- **🎨 Rich Text Tools**: Adjust font size, color, bold, and italic styles on the fly.
- **🔳 Smart Selection**: Use the drag-to-select box to crop and extract specific text sections.
- **↕️ Precision Movement**: Use the "Move" tool to reposition any element exactly where it belongs.
- **📂 Multi-page Support**: Seamlessly navigate and edit large documents with full page-state persistence.
- **🔒 Privacy First**: Your PDFs never leave your device. All processing happens locally in your browser.
- **🆓 Completely Free**: No subscriptions, no limits, no account creation required.

## 🛠️ Built With

- **[Next.js](https://nextjs.org/)** - React framework for the frontend.
- **[pdf-lib](https://pdf-lib.js.org/)** - For robust, high-performance PDF manipulation.
- **[PDF.js](https://mozilla.github.io/pdf.js/)** - For high-quality document rendering.

## 🏃 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm (or your preferred package manager)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/pdfflow.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 💡 Workflow

1. **Upload**: Drag and drop your PDF file onto the workspace.
2. **Edit**: Select the text tool to add new content, or use the selection tool to "crop-extract" and modify existing text.
3. **Format**: Customize fonts, sizes, and colors directly on the canvas.
4. **Export**: Hit Download to save your modified PDF instantly with all changes preserved.

## 🌙 Theme Support

PDF-Flow supports both Light and Dark modes to ensure a comfortable editing experience at any time of day. Toggle themes directly from the navbar on the landing page.
